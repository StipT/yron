# yron

Gym app

## Monorepo

This project uses Melos to manage the app and shared packages.

- `.` — Flutter app
- `packages/yron_data` — data/API layer (pure Dart)
- `packages/yron_ui` — shared UI components and theme

Bootstrap the workspace with `dart run melos bootstrap`.
Run all package tests with `dart run melos run test`.
